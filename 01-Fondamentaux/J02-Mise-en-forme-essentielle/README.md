# Jour 2 — Mise en forme essentielle

> Bootcamp Excel → Excel avancé → Power Query → Power Pivot
> Sprint 1 — Fondamentaux · J02 / 30

## 🎯 Objectif du jour

Apprendre à utiliser la mise en forme d'Excel de manière fonctionnelle et
professionnelle, afin de rendre les données plus lisibles **sans modifier
inutilement les valeurs stockées**.

À la fin de cette journée, je dois savoir :

- distinguer une valeur de son format d'affichage ;
- formater correctement des nombres, pourcentages, devises et dates ;
- améliorer la lisibilité d'un tableau (largeur des colonnes, alignement, bordures) ;
- comprendre les bons usages (et les pièges) de la fusion de cellules ;
- appliquer ces notions dans un mini-projet de bulletin scolaire.

## 🧠 Notions abordées

- Valeur d'une cellule vs. format d'affichage
- Formats de nombres (décimales)
- Format pourcentage
- Format monétaire (format personnalisé `# ##0" FCFA"`)
- Formats de date
- Mise en évidence des en-têtes, largeur des colonnes, alignement, bordures
- Fusion de cellules : bon usage (titres) vs. mauvais usage (données structurées)

## 🛠️ Exercices réalisés

1. **Exercice 1 — Les formats indispensables** : nombres à 2 décimales,
   pourcentage (`0,95 → 95 %`), devise (`75000 → 75 000 FCFA`), date
   (`2026-01-15 → 15/01/2026`).
2. **Exercice 2 — Rendre le tableau lisible** : en-têtes en gras, largeur de
   colonnes ajustée, alignement, bordures, cohérence des formats.
3. **Exercice 3 — La fusion** : titre `BULLETIN DES ÉTUDIANTS — BOOTCAMP DATA`
   fusionné et centré au-dessus du tableau.
4. **Mini-projet — Bulletin scolaire** : feuille `Bulletin` avec en-tête,
   résultats (Math / Excel / Python) et informations complémentaires
   (présence, frais payés, date d'inscription), mise en forme professionnelle.
